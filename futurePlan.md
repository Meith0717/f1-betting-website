# F1 Betting Application

## Concept

Describes the concept of the Application

### Usage

- First start (no users)
  - Admin register with username and password
- Users log in by Username & Password
  - Two Roles: Admin & User
  - registration only via invitation-email  
    - contains username and password

### Gameplay

- User places a bet on sprints and race
  - Selects three driver he think will win
- Bets are open between the qualifying and race 
- Scoring:
  - Right driver +1
  - Right Team +1
  - Perfect Podium +2  
- Total score is the sum of all bets results 
  - If two users have equal total score:    
    - The one who hat the highest total score first stays on top
